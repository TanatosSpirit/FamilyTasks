# Разделители по датам в списке задач

При сортировке «По сроку» (`SortOrder.DUE_DATE`) и фильтре активных задач список автоматически разбивается на именованные секции по дедлайну. Каждая секция отделяется горизонтальной полосой с подписью слева; секция создаётся только если на эту дату есть хотя бы одна задача.

---

## Секции и их порядок

| Секция | Условие | Положение |
|---|---|---|
| **Просрочено** | `dueDate < todayStart` (до полуночи сегодняшнего дня) | первая |
| **Сегодня** | `dueDate` попадает в текущие календарные сутки | после «Просрочено» |
| **Завтра** | `dueDate` попадает в следующие календарные сутки | следующая |
| **Пт 25 июля** | остальные будущие дни | по возрастанию даты |
| **Без срока** | `dueDate == null` | последняя |

«Просрочено» — единая секция для всех истёкших задач независимо от того, на сколько дней они просрочены.

Задачи с дедлайном в текущем дне, но уже прошедшим временем (например, 10:00 при текущем 15:00) **не** попадают в «Просрочено» — они остаются в «Сегодня», а красный цвет времени уже сигнализирует о просрочке (см. `dueDateColor`).

---

## Когда разделители не показываются

- Сортировка «По приоритету» или «По дате создания» — порядок задач не связан с датой.
- Фильтр «Готово» — там сортировка по `completedAt`, не по дедлайну.

---

## Реализация

Всё находится в `TaskListScreen.kt`, ViewModel не затронута.

**`sealed class TaskListItem`** — обёртка элемента списка:
- `Header(label: String)` — заголовок секции
- `Item(task: Task)` — карточка задачи

**`buildDateGroupedList(tasks)`** — трансформирует плоский список задач в `List<TaskListItem>`:
1. Разделяет задачи на три группы по `dueDate` относительно `todayStart` (полночь текущего дня).
2. Группу «с дедлайном» (`dueDate >= todayStart`) дополнительно группирует по дню через `Calendar` с обнулёнными часами/минутами/секундами.
3. Ключи дней сортируются (`byDay.keys.sorted()`) — порядок гарантирован независимо от порядка задач во входном списке.
4. Метка «Пт 25 июля» формируется через `SimpleDateFormat("EE d MMMM", Locale("ru"))` с `replaceFirstChar { it.uppercaseChar() }`.

**`DateGroupHeader`** — Composable: `HorizontalDivider` + `Text` в `labelMedium` цвета `onSurfaceVariant`.

**`LazyColumn`** итерируется по `listItems` через единый `items(...)`. Ключ элемента:
- для `Header` — `"header_${label}"` (строка уникальна внутри одного экрана)
- для `Item` — `task.id` (UUID)

---

## Граничные случаи

- Список задач пустой → `buildDateGroupedList` не вызывается (экран пустого состояния).
- Все задачи без дедлайна → только секция «Без срока».
- Все задачи просрочены → только секция «Просрочено».
- Одна задача в секции → секция всё равно показывается (разделитель + метка).
